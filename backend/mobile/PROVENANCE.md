# Portable mobile runtime provenance

The lib/desktop.mjs, lib/events.mjs, lib/http.mjs, lib/native-i18n.mjs, lib/native-proxy.mjs, lib/stream.mjs and web/* code were copied from the user-authorized local agy-pocket implementation on 2026-11-15. The original server entrypoint and all configuration, credentials, backups, logs and history were excluded. The new server.mjs, tunnel.mjs and lib/auth.mjs replace the prior dsh-pocket runtime dependency. Runtime imports and asset lookup are relative to this directory.

The bundled vendor/upstream-i18n/ui_v2.json and common.json came from EasyAntigravity revision 9be224fbf96a70a0cb496cf638b9606b755dd0fb through the approved agy-pocket vendor copy. These resources and native-i18n's exact-label adaptation carry the included MIT license, Copyright (c) 2026 Astwarp. Preserve vendor/upstream-i18n/LICENSE in redistribution. The common dictionary also carries the Goagy branding adaptation used by this independent runtime. The Pocket code was authored in this local development workspace; no separate third-party license was supplied for that first-party code.

Run node tunnel.mjs from this directory using Node 22.13+. GOAGY_POCKET_MODE defaults to quick. Fixed mode requires GOAGY_POCKET_FIXED_URL (HTTPS origin) and GOAGY_POCKET_CF_CONFIG (absolute external YAML path); cloudflared reads that file in place. No credentials or private configuration are copied. GOAGY_CLOUDFLARED may identify an installed executable; otherwise Windows installation directories/PATH are searched.

Only JSON status/error records are emitted by the supervisor. The initial record deliberately supplies the PIN to the owning desktop manager and must not be exposed in public logs. Quick hostnames are temporary; Cloudflare documents no SLA and no SSE support for Quick Tunnels. Compatibility UI uses finite /goagy-pocket/api/live requests and falls back to regular REST polling after failures. Native desktop WebSocket transport is retained.

CLI reference checked 2026-11-15: https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/run-parameters/ (tunnel flags precede run); https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/ (Quick Tunnel limitations).
