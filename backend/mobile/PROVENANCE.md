# Portable mobile runtime provenance

The lib/desktop.mjs, lib/events.mjs, lib/http.mjs, lib/native-i18n.mjs, lib/native-proxy.mjs, lib/stream.mjs and web/* code were copied from the author's earlier local mobile runtime on 2026-11-15. The original server entrypoint and all configuration, credentials, backups, logs and history were excluded. The new server.mjs, tunnel.mjs and lib/auth.mjs replace the earlier external runtime dependency. Runtime imports and asset lookup are relative to this directory.

The bundled vendor/upstream-i18n/ui_v2.json and common.json came from the project's earlier revision 9be224fbf96a70a0cb496cf638b9606b755dd0fb through the approved vendor copy. These resources and native-i18n's exact-label adaptation carry the included MIT license, Copyright (c) 2026 Astwarp. Preserve vendor/upstream-i18n/LICENSE in redistribution. The portable mobile code was authored in this local development workspace; no separate third-party license was supplied for that first-party code.

Run node tunnel.mjs from this directory using Node 22.13+. GO_ANTIGRAVITY_MOBILE_MODE defaults to quick. Fixed mode requires GO_ANTIGRAVITY_MOBILE_FIXED_URL (HTTPS origin) and GO_ANTIGRAVITY_MOBILE_CF_CONFIG (absolute external YAML path); cloudflared reads that file in place. No credentials or private configuration are copied. GO_ANTIGRAVITY_CLOUDFLARED may identify an installed executable; otherwise Windows installation directories/PATH are searched.

Only JSON status/error records are emitted by the supervisor. The initial record deliberately supplies the PIN to the owning desktop manager and must not be exposed in public logs. Quick hostnames are temporary; Cloudflare documents no SLA and no SSE support for Quick Tunnels. Compatibility UI uses finite /mobile/api/live requests and falls back to regular REST polling after failures. Native desktop WebSocket transport is retained.

CLI reference checked 2026-11-15: https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/run-parameters/ (tunnel flags precede run); https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/ (Quick Tunnel limitations).
